Builder — fill the table

  • Copy a whole day from any earlier plan, hers or another athlete's, then edit cells.
  • Number cells open a pad with her usual values on top (12, 15, 20…); "next" jumps reps → sets → next row.
  • The pad types Latin digits itself, so the Persian-keyboard digit problem never happens. Tap a link dot between rows to make a superset.
