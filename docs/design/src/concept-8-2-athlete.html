Profile — plans

  • The person icon in the day view opens this. On top is what she checks before writing a plan: level, height, goal, and injuries in yellow. The phone number under the name calls.
  • Plans newest first. The current one is outlined in pink, and its day letters open that day. A plan that hasn't started yet is marked بعدی. Other plans show only their start date: the plan list has no day counts.
  • Tapping an older plan opens it in the day view. "+ برنامه جدید" starts the copy-first flow.

Profile — measurements

  • One measurement at a time: weight first, the chips switch to the other five. The latest value and the change since the first check-in sit above the line.
  • Time runs right to left, like the text. Worth checking with her: some people read charts left to right even in Persian.
  • Check-ins newest first. Tapping one opens it to edit or delete.

Add measurement — a sheet

  • Opens over the profile with today's Jalali date. Six fields, each with the last value under it, so the change shows while she types.
  • She fills only what she measured: the API needs at least one value. Persian digits and "٫" are converted before sending.
  • The same sheet edits a check-in, with a delete button.

New athlete — one form

  • Name, surname and mobile are required. The rest says اختیاری.
  • Private or public starts on the tab she came from, and level is three buttons, so the only typing is names, phone, goal, height and injuries.
  • The profile's pencil opens the same form, filled in. Editing an athlete has no endpoint yet (see Gaps in the README).
