# Discussions

Product and business conversations, kept as records: the questions asked, the answers given at
the time, and the recommendation that came out of them. They aren't committed scope and they
aren't specs. If a discussion changes what gets built, the change goes into
[tasks/](../tasks/README.md) or [product-direction.md](../product-direction.md), and the
discussion stays here as the reasoning behind it.

One file per conversation, named `YYYY-MM-DD-<topic>.md`. Don't rewrite one after the fact. If
the answers change, start a new discussion and link back to the old one.
